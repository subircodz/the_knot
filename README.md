# The Cozy Knot & Co.

A responsive brand storefront for a cake, gifting and celebration business.

## Current build

The first version is a lightweight static website built with HTML, CSS and vanilla JavaScript.

- Brand-led homepage
- Product category discovery
- Occasion-led browsing
- Brand story section
- Contact/enquiry call to action
- Responsive mobile navigation
- Basic page metadata for search engines

## Run locally

No build tools or package installation are required.

1. Clone the repository.
2. Open `index.html` in a browser.

For a local development server, you can use the Live Server extension in VS Code.

## Before launch

Replace the temporary photography and placeholder contact details with approved business assets and verified information.

Business details still to confirm:

- Official logo and brand guidelines
- Business location and delivery coverage
- Phone number and WhatsApp ordering number
- Official email and social links
- Product catalogue, descriptions and prices
- Order lead times, delivery fees and payment methods
- Corporate gifting process

Do not publish placeholder contact information as a real business contact.
